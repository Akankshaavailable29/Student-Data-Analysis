# Project Summary

**Project:** Student Data Analysis using Python  
**Libraries:** Pandas, NumPy, Matplotlib, Seaborn  
**Workflow:** Load data → inspect quality → validate ranges → handle missing values → summarize by department → visualize patterns → interpret limitations.

**Data provenance:** The included CSV is synthetic and intended for portfolio practice. Results must be recalculated by running the notebook. Do not present this dataset as real institutional data.
